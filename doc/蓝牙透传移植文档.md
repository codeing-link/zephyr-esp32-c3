# 蓝牙透传移植文档

## 分层

`ttm_protocol.c/.h` 是平台无关层，不包含 Zephyr 头文件，负责 UART AT 命令解析、参数校验和透传路由。`main.c` 是 ESP32-C3 Zephyr 适配层，负责 GATT、广播、UART、GPIO 和复位。

## 移植步骤

保留 `ttm_protocol.*`，在新平台实现 `struct ttm_port`：UART 发送、BLE 通知、连接状态、串口改波特率、发射功率、广播重启、连接参数、配置保存与系统复位。然后建立 `FFF0` 主服务、`FFF3` 写特征和 `FFF4` 通知特征，并把回调分别连接到 `ttm_protocol_on_ble()` 与 `ttm_protocol_on_uart()`。

## 注意事项

目标 ATT MTU 为 153，因此单包有效数据最多 150 字节。需要掉电保持的参数应在新平台的 `save_config` 回调中使用 Flash、NVS 或 KV 存储实现；当前 ESP32-C3 适配层预留该接口。
